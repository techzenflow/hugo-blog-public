[details=“Gemini AI Pro 思考模式（3 Pro）”] 搭建 Sing-Box 内核的 VLESS + WebSocket (WS) + TLS + CDN 方案，重点在于配置文件的编写。这个组合的优势在于它可以隐藏在正常的 HTTPS 流量中，并且可以套用 Cloudflare 等 CDN 来隐藏真实 IP。

以下是详细的手动配置指南和完整的 config.json 文件结构。

1. 核心准备工作

在编写配置之前，请确保你已经准备好：

  • 域名：托管在 Cloudflare（如果需要 CDN 功能）。
  • 证书：域名的 SSL 证书文件（.crt 和 .key）。推荐使用 acme.sh 或 certbot 申请免费证书。
  • UUID：生成一个 UUID 作为密码（命令行输入 sing-box generate uuid 即可获得）。

2. 服务端配置文件 (Server)

在服务器上，Sing-Box 的配置文件通常位于 /etc/sing-box/config.json。

关键点说明：

  • Inbounds (入站)：配置 vless 协议，监听 443 端口。
  • Transport (传输层)：指定 ws (WebSocket)，并设置 path（路径）。
  • TLS：开启 TLS，并指向你的证书文件路径。

  4. Path: /yourpath 是 WebSocket 的路径，可以自定义（如 /chat），客户端必须填一样的。

3. 关于 CDN (Cloudflare) 的设置

要启用 CDN（隐藏 IP）：

  1. Cloudflare 后台：在 DNS 设置中，将你的域名记录（A 记录）的“代理状态”由 灰色云朵 改为 橙色云朵 (Proxied)。
  2. SSL/TLS 设置：在 Cloudflare 的 SSL/TLS 选项卡中，将加密模式设置为 Full (Strict)。
    • 原因：我们的 Sing-Box 配置了真实有效的证书，所以用 Strict 模式最安全且不容易报错。

配置文件说明：

  • port：设置服务器监听的端口，一般来说 HTTPS 用 443 端口。
  • protocol：设置协议为 vless。
  • settings.clients.id：这是一个 UUID，表示用户的唯一标识符，客户端需要使用这个 ID。
  • fallbacks：如果你想利用 CDN 的伪装功能，可以配置 fallback，并设置 path 和 headers，它们需要和 CDN 设置一致。
  • streamSettings.network：设置为 ws，表示使用 WebSocket 协议。

  • TLS 证书：如果你的 CDN 提供 SSL/TLS 终端，确保正确配置。
  • WebSocket 协议支持：确保 CDN 支持 WebSocket 流量，并启用了适当的 WebSocket 参数。
