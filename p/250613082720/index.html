Windows连接WebDAV服务

Jun 13, 2025
  1. 简介
  2. 文件资源管理
  3. cmd的 net use
  4. powershell的 Invoke-WebRequest

简介

WebDAV 的核心是 HTTP 协议的扩展，可以把 WebDAV 想象成一个“架设在互联网上的网络 U 盘”。它是一种技术标准，允许你像操作本地电脑里的文件一样，通过网络来管理（查看、上传、下载、修改、删除）远程服务器上的文件和文件夹。

Windows 连接 WebDAV 有几种方法：

  • 文件资源管理器
  • cmd的 net use
  • powershell的 Invoke-WebRequest

文件资源管理

cmd的 net use

前提条件：

  1. WebDAV 服务器已配置且可访问。（例如 Windows Server IIS WebDAV、Nextcloud、Seafile、群晖等）
  2. 网络连接正常。
  3. 已启用 WebClient 服务（Windows WebDAV 客户端）：
    • 按  Win + R，输入  services.msc；
    • 找到  WebClient  服务，确保其为运行状态，并设置为“自动”启动。

语法：

1

net use [驱动器盘符]: "\\服务器地址@需求认证的端口\路径" /user:用户名 密码 /persistent:yes

示例：

1

net use Z: "\\webdav.example.com@80\webdav" /user:myusername mypassword /persistent:yes
