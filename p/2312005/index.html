简介

安装

提示

推荐 FVM 版本管理工具安装 Flutter

FVM，Flutter 的多版本管理工具](https://blog.seektao.cc/p/2403003)

要下载 Windows x64 版本的 Flutter SDK，你需要将原始 URL：

1

https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.38.5-stable.zip

改为镜像 URL：

1

https://storage.flutter-io.cn/flutter_infra_release/releases/stable/windows/flutter_windows_3.38.5-stable.zip

注意：并非所有镜像都支持直接从 URL 下载。

Linux：

官方教程：https://docs.flutter.cn/get-started/install/linux

安装其他平台的依赖

Android Studio

在安装 flutter 以后，为了开发安卓程序，还需要安装 Android Studio，安装步骤跟着 Android Studio 界面操作即可

打开后进入设置，找到Languages & Frameworks，配置如下内容：

  • 找到 SDK Platforms，下载 Android SDK 如 16.0 15.0 等等
  • 找到 SDK Tools，下载 cmdline-tools： 勾选如下内容后确定
    • Android SDK Command-line Tools(latest)

Visual Studio

在安装 flutter 以后，为了开发 Windows 桌面程序，还需要安装 Visual Studio，安装步骤跟着 Visual Studio 界面操作即可

下载地址：https://visualstudio.microsoft.com/downloads/

选择：使用 C++桌面开发

如果你 C 盘紧张，进入安装位置修改为其他盘

配置

查看 Flutter 配置情况

1
2

flutter doctor -v
# 简略显示：flutter doctor -

配置 android-sdk

1

flutter config --android-sdk="D:\develop\Android\Sdk"

配置 jdk-dir

1

flutter config --jdk-dir="D:\develop\Java\jdk-17"

配置镜像源

清华源

帮助文档：https://mirror.tuna.tsinghua.edu.cn/help/flutter/

长期使用 TUNA 镜像：

1
2

echo 'export FLUTTER_STORAGE_BASE_URL="https://mirrors.tuna.tsinghua.edu.cn/flutter"' >> ~/.bashrc
echo 'export PUB_HOSTED_URL="https://mirrors.tuna.tsinghua.edu.cn/dart-pub"' >> ~/.bashrc

在编译 android 项目时，flutter 还会从 https://storage.googleapis.com/download.flutter.io 下载 Java 程序库，您可以在 Android 项目目录下的 build.gradle 中添加下面一行下载源，从而使用 TUNA 镜像。

1
2
3
4
5
6
7

allprojects {
    repositories {
        google()
        jcenter()
        maven { url 'https://mirrors.tuna.tsinghua.edu.cn/flutter/download.flutter.io' }
    }
}

Flutter SDK 的更新会从 Github 获取，如您的开发设备访问 Github 速度慢，可以在 开发设备的 Flutter SDK 目录 运行下面的命令，将 Git 上游设置为 TUNA 镜像：

1

git remote set-url origin https://mirrors.tuna.tsinghua.edu.cn/git/flutter-sdk.git
