pyenv-win，Windows下的Python环境，项目管理工具

Feb 15, 2025
  1. 简介
  2. 安装
    1. Powershell
  3. 卸载
  4. 配置
  5. 使用
  6. 插件
    1. pyenv-virtualenv

简介

官网：https://github.com/pyenv-win/pyenv-win

安装

Powershell 

1

Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/pyenv-win/pyenv-win/master/pyenv-win/install-pyenv-win.ps1" -OutFile "./install-pyenv-win.ps1"; &"./install-pyenv-win.ps1"

这个安装会家目录添加 .pyenv 文件夹，会在当前用户添加如下环境变量

  • PYENV
  • PYENV_HOME
  • PYENV_ROOT

PATH下

  • C:\Users\用户名\.pyenv\pyenv-win\bin
  • C:\Users\用户名\.pyenv\pyenv-win\shims

重新打开终端运行 pyenv即可

如果出现权限问题，使用管理员打开 powershell，运行下面的命令之后重新安装

1

`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine`

默认安装的位置

1

%USERPROFILE%\.pyenv

卸载 

1
2

cd $HOME/.pyenv\pyenv-win
.\install-pyenv-win.ps1 -Uninstall

配置

设置加速镜像源

添加环境变量 PYTHON_BUILD_MIRROR_URL，值为：

1

https://jedore.netlify.app/tools/python-mirrors/

使用

查看可下载的版本

1

pyenv install --list

安装指定的版本

1

pyenv install 3.12

设置全局版本

1

pyenv global 3.12

查看所有可用的python

1

pyenv versions

查看当前的版本

1

pyenv version

插件

pyenv-virtualenv

pyenv-virtualenv is a pyenv plugin that provides features to manage virtualenvs and conda environments for Python on UNIX-like systems.
