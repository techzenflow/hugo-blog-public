问题 1

VMware workstation 在 nat 网络模式下，宿主机无法 ping 通虚拟机，虚拟机可以 ping 通宿主机

环境：Windows 10 专业工作站版

已经经历过的操作：

  1. 重置 vmware network adapter vmnet8 网卡，无效
  2. 禁用 vmware network adapter vmnet8，重新启用，无效

解决办法

Windows 进入控制面板-系统和安全-Windows defer 防火墙-高级设置-入站规则-启用规则：文件和打印机共享(回显请求 - ICMPv4-In)

再尝试从宿主机 ping 虚拟机

总结

根据这个规则设置，可以判断大概率是 Windows 安全设置导致，而非 VMware 本身的问题，但是在此之前，已经重置过 VMware 虚拟网络 nat 网卡，不排除 VMware 的问题，但是在 Windows 环境下，首先应该更改 window 安全设置之后再尝试其他方法

问题 2

VMware workstation 在 nat 网络模式下，虚拟机无法 ping 通宿主机，宿主机可以 ping 通虚拟机

环境：Windows 10 专业工作站版

已经经历过的操作：

  1. 重置 vmware network adapter vmnet8 网卡，无效
  2. 禁用 vmware network adapter vmnet8，重新启用，无效

解决办法

虚拟机 IP 网关设置为 xxx.xxx.xxx.2 而非 xxx.xxx.xxx.1
