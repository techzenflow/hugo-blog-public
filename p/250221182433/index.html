alist-tvbox，AList代理，支持xiaoya版AList界面管理

Feb 21, 2025
  1. 简介
    1. 功能
  2. 部署
    1. native 版本

简介

alist-tvbox 是一个 AList 代理，支持 xiaoya 版 AList 界面管理

源码：https://github.com/power721/alist-tvbox

功能

  • 管理界面
  • 海报墙
  • 多个 AList 站点
  • 多个阿里云盘账号
  • 挂载我的云盘
  • 支持夸克、UC、115 网盘
  • 自动签到
  • 自动刷新阿里 Token
  • 自定义 TvBox 配置
  • 安全订阅配置
  • TvBox 配置聚合
  • 添加阿里云盘分享
  • 添加 PikPak 分享
  • 支持 BiliBili
  • 管理 AList 服务
  • 小雅配置文件管理
  • 构建索引
  • 在线日志

version: '3.9'

services:
  xiaoya-tvbox:
    image: 'haroldli/xiaoya-tvbox:native'
    container_name: xiaoya-tvbox
    restart: unless-stopped
    volumes:
      - './xiaoya-tvbox_data:/data'
    environment:
      - ALIST_PORT=5344
    ports:
      - '5344:80'
      - '4567:4567'
    deploy:
      resources:
        limits:
          cpus: '0.85'  # 限制 CPU 最大 85%
    networks:
      - alist_network

networks:
  alist_network:
    external: true
